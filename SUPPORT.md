# Support

xqnet is an open-source reference implementation.

- Use GitHub Issues for reproducible bugs and narrowly scoped feature requests.
- Use repository discussions (if enabled) for broader design questions.
- Use the private process in `SECURITY.md` for vulnerabilities.

When reporting a bug, include the xqnet version, operating system/architecture,
adapter, command line, relevant manifest/version information and the smallest
safe input that reproduces the issue.

Do not attach packet captures or network logs unless you are entitled to share
them and have reviewed them for sensitive information.

The project does not guarantee commercial support or response-time SLAs through
the public repository.
